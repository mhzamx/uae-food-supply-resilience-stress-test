## Reproducibility and release checks

The PortWatch snapshot and hashes anchor the frozen corridor series. Generic API base links in Comtrade and FAO records identify the service but do not reproduce a query by themselves. Retain extraction parameters/SQL, complete responses or exports, classification version, reporter/partner/flow/year, requested code lists, pagination checks, units, retrieval date and file hashes in the packaged data model. This QC did not independently replay every original API extraction; several endpoints could not be recovered through web retrieval.

For Comtrade preserve reporter 784, year 2023, original H6, subgroup whitelists, World-versus-partner distinction, observed RX/DX/X and missing net weight. Preserve known-weight lower bounds for the oil core. For FAO preserve item codes, Food versus tourism, equivalent units, residuals, the FBS population denominator and the accounting production rule. Low confidence for pulses remains material.

The frozen PortWatch script uses filenames with a fixed cut suffix even in fetch mode and queries live data without an explicit end date. The README therefore documents reproduction from the frozen snapshot only, and reproduction must use the supplied snapshot. The operative script is `src/p2_corridors_v0.2.py` in this repository (SHA-256 `72e47c69529f161d5377191e2512b67db474519e83287c8d1d91622f209eb42f`).

## Companion files

`P2_Source_QC.csv` has one reviewed row per source (S01–S89); `P2_Source_Link_QC.csv` has the retrieval outcome for each of the 99 attempted URLs: `lines` is the number of lines returned by the retrieval tool, including error messages (not necessarily text from the source), `access` is the outcome and `detail` gives the failure reason when one was recorded. In this public copy, internal tool references are removed and failure messages are written as plain descriptions; URLs, outcomes and reasons are unchanged. No source was silently deleted and no frozen scope changed. E-numbers (for example E38) refer to entries in the project's decision log, which is not published.
